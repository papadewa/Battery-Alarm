# Battery Cat — proyek lengkap

Gunakan folder ini sebagai folder proyek yang akan dipindahkan. Isinya adalah salinan lengkap dari folder kerja Battery Cat: source code, aset, lisensi, `.venv`, `.impeccable`, `build`, `dist`, `qa`, `release`, konfigurasi installer, dokumentasi, dan pengujian.

Installer terbaru berada di `release/Battery-Cat-1.1.2-Windows-x64-Setup.exe`.

Folder ini sengaja dibuat terpisah dari file root Account Manager. Pemeriksaan akhir membandingkan struktur file sumber dan hasilnya: 6.864 file sumber, 6.864 file di folder ini, tidak ada yang hilang dan tidak ada file tambahan dari Account Manager.

Folder `battery-cat` asli tetap dipertahankan sebagai cadangan.
