# Battery Cat

Offline desktop battery companion for laptop users. A transparent cat alarm-clock widget shows real battery percentage, source of power, estimated runtime where provided, and configured thresholds. Low and target-charge alarms have sound, acknowledge, and snooze controls. User preferences persist locally. Windows installer is the first verified distribution; Qt and psutil keep application source portable to macOS and Linux.

The existing cream and peach cat artwork is the visual authority. Keep this project independent of the parent Account Manager application. No accounts, telemetry, network service, or automatic charging control. Battery reading is the system-reported aggregate. Charger connected does not imply actively charging. Monitoring does not run while the OS sleeps.
